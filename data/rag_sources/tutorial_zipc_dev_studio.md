# 　ＺＩＰＣ入门












## １-１　需求确认
  最开始要对建立的项目需求进行确认。



  在本教程中，将边制作CD播放器样例，边解说ZIPC中的开发流程。

**CD播放器的需求**

1. 有电源按钮，初始状态为电源OFF。
2. 接通电源的话，最开始为电源ON状态，并且停止。
3. 有出入仓按钮，按下该按钮的话，立即终止播放，托盘出仓。另外，将电源设为OFF时，也将立即终止播放，并处于电源OFF状态。
4. 按下播放按钮的话，进行播放。
5. 停止过程中只有按下电源按钮、出入仓按钮及播放按钮时，才会发生状态变化。
6. 有停止按钮，按下该按钮的话，会从播放状态变为停止状态。
7. 有暂停按钮，播放时按下该按钮的话，播放会暂时停止，再按一次的话，会继续播放，并返回到播放状态。
8. 有快进按钮，播放时按下该按钮的话，开始快进，松开该按钮的话，返回播放状态。
9. 有倒退按钮，播放时按下该按钮的话，开始倒退，松开该按钮的话，返回播放状态。



  这样，就确定了接下来要制作的CD播放器的需求。

### １-３-２　文档树
     在“文档树”中进行各设计书的管理。

     在“文档树”的各项目中，注册的内容如下所示。



**◆ZIPC设置文件**

   在【ZIPC设置文件】项目中注册的是“ZIPC关键字文件（.zkw）”以及“关键字文件（.kwd）”。

  “ZIPC关键字文件”用来注册系统调用以及仿真器调用。可以通过修改“ZIPC关键字文件”的内容来改变关键字

  “ZIPC关键字文件”是在项目建立时自己注册的。

  “关键字文件”用来注册ZIPC中使用的符号。



**◆全体文档**

    在【全体文档】项目中注册的是分析时建立的设计书（如任务关联图、序列图以及时序图等）。在【全体文档】项目中可以建立用于将设计书进行分类的项目，在每一个项目中可以注册文档。另外，也可以注册和管理与项目相关的各外部应用文件。



**<u>全体文档项目中注册的设计书在“设计阶段”以外没有关联。</u>**



**◆控制器**

在“控制器”项目中可以添加“任务”项目、“句柄”项目、“系统共通”项目、“任务共通”项目以及“句柄共通”项目。

在这些项目注册各设计书。注册的设计书为“仿真阶段”、“动画阶段”、“模拟阶段”以及“目标阶段”的对象设计书。





**◆系统共通**

    在【系统共通】项目中注册在任务全体以及句柄全体中使用的通用设计书。



**◆任务**

在【任务】项目中注册各任务中使用的设计书。

在【任务共通】项目中注册在任务全体中使用的设计书。

另外，在【任务】项目中可以设定任务信息。

使用OS的话，添加多个任务，将各任务中使用的设计书注册到各任务项目中。

不使用OS的话，添加一个任务项目，将各任务中使用的设计书注册到添加的任务项目中。（不使用OS的话，也可以建立多个任务，但是不能够进行仿真。这种情况下，不能够进行任务切换，是作为单任务来进行动作的，而不是多任务）



**◆句柄**

在【句柄】项目中注册各句柄中使用的设计书。

在【句柄共通】项目中注册在全体句柄中使用的设计书。

另外，在【句柄】项目中可以设定句柄信息。

添加开发的句柄项，使用添加的句柄将所用的设计书注册到添加的句柄项目中。（不使用OS的话，可以建立多个句柄。不使用OS时的句柄一般为中断处理） 



在ZIPC中，用户对所有设计书进行管理。**将存在项目文件的文件夹移到别处时，该文件夹下的各设计书的路径也会相应发生变化**。注册比项目文件所处的目录级别高的各设计书时，不改变路径。

### １-３-５　状态转移表的定义
在这里，定义“CD播放器”项目的状态转移表。



在编辑“CD.stm”之前，再确认一下“CD播放器”的需求。



•有电源按钮，初始状态为电源OFF。

•接通电源的话，最开始为电源ON状态，并且停止。

•有出仓/入仓按钮，按下该按钮的话，立即终止播放，托盘出仓。另外，将电源设为OFF时，也将立即终止播放，并处于电源OFF状态。

•按下播放按钮的话，进行播放。

•停止过程中只有按下电源按钮、出仓/入仓按钮及播放按钮时，才会发生状态变化。

•有停止按钮，按下该按钮的话，会从播放中状态变为停止状态。

•有暂停按钮，播放时按下该按钮的话，播放会暂时停止，再按一次的话，会继续播放，并返回到播放中状态。

•有快进按钮，播放时按下该按钮的话，开始快进，放开该按钮的话，返回播放状态。

•有倒退按钮，播放时按下该按钮的话，开始倒退，放开该按钮的话，返回播放状态。





    状态转移表是利用外部的事件来表示从某个状态转移到另一个状态的一种形式。建立状态转移表的前提是抽出事件（event）与状态（state）。

    首先来抽出事件。从需求中抽出的事件为：“电源按钮”、“出入仓按钮”、“播放按钮”、“停止按钮”、“暂停按钮”、“快进按钮按下”、“暂停按钮松开”、“倒退按钮按下”、“倒退按钮松开”。

    然后抽出状态。从需求中抽出的状态为：“电源ON”、“电源OFF”、“插入CD”、“未插入CD”、“停止”、“播放”、“倒退”、“快进”和“暂停”。

下面，简单介绍一下设定的STM相关的内容。



**◇STM类别**

在【STM类别】选项中，进行状态转移表的驱动形式、STM所属的设定。

在“CD.stm”设计书中，指定表示状态转移表基本动作的“E型通常”。

“E型通常”的意思是，“E型”表示动作类别，表明驱动类型为“事件驱动型”。“通常”表示状态转移表的种类。状态转移表的种类除了“通常”外，还有“子程序”、“库”。

有关“STM类别”的详细介绍，可参考《状态转移表手法书入门》。



**◇STM名称**

在【STM名称】栏中，设定状态转移表的名称。ZIPC中，对STM名称有如下所示的规约。

・STM名称规约

**①STM名称不能全为数字。**

**②STM名称大多数为1个记号（不能有符号、运算符、空格、制表符以及换行）。（也有例外，如克隆STM等，在这里不做介绍）**

在“CD.stm”设计书中，将“STM名称”指定为“CD”。



**◇阶层号**

在【阶层号】栏中，进行状态转移表阶层化的设定。

状态转移表的阶层化是指判断状态转移表父子关系的阶层号。

阶层化时，为了判断哪个状态转移表为父，哪个为子，就需要该阶层号。

阶层号结构为树型构造，最上边的父阶层为“0”时，“0”的子阶层为“0.1”、“0.2”等。而“0.1”的子阶层为“0.1.1”等。

・阶层号的树型构造



在“CD.stm”设计书中，由于建立了顶层状态转移表，因此，将【阶层号】指定为“0”。有关阶层化、阶层号的详细介绍，可参考《状态转移表手法入门》。

### １-３-８　动作单元格的编辑
    在这里，进行“CD.stm”设计书的动作单元格的编辑。
